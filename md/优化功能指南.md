# 社区论坛项目 - 优化功能指南

## 📋 优化概览

本文档详细列出了社区论坛项目的优化方向，按照优先级和类别进行分类，帮助您有计划地提升系统性能、安全性和用户体验。

## 🎯 优先级定义

- **高优先级**：必须尽快实现，直接影响系统安全性和核心功能
- **中优先级**：建议在功能稳定后实现，提升系统性能和用户体验
- **低优先级**：可在后期迭代中实现，优化代码质量和可维护性

---

## 🔒 安全性优化（高优先级）

### 1. 密码加密

**当前问题**：直接存储明文密码，存在严重安全隐患

**优化方案**：
- 使用 BCrypt 加密算法对密码进行哈希处理
- 实现步骤：
  1. 添加 BCrypt 依赖
  2. 修改 `UserServiceImpl` 中的注册和登录方法
  3. 密码存储前进行加密，验证时进行解密对比

**代码示例**：
```java
// 添加依赖
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-crypto</artifactId>
</dependency>

// 密码加密
String encryptedPassword = BCrypt.hashpw(password, BCrypt.gensalt());

// 密码验证
if (BCrypt.checkpw(password, user.getPassword())) {
    // 密码正确
}
```

**优先级**：高

### 2. JWT 认证

**当前问题**：未实现 token 认证，无法进行权限控制

**优化方案**：
- 实现 JWT token 的生成和验证
- 添加 token 过期时间和刷新机制
- 实现基于 token 的权限控制

**实现步骤**：
1. 添加 jjwt 依赖
2. 创建 JWT 工具类
3. 修改登录接口返回 token
4. 添加拦截器验证 token
5. 从 token 中获取用户信息

**优先级**：高

---

### 3. 请求参数校验

**当前问题**：参数校验不够严格，存在安全风险

**优化方案**：
- 使用 Spring Validation 进行参数校验
- 对所有输入参数进行边界检查
- 防止 SQL 注入和 XSS 攻击

**实现步骤**：
1. 在 DTO 类中添加校验注解
2. 在控制器方法中添加 `@Valid` 注解
3. 实现全局异常处理器处理校验错误

**优先级**：高

---

### 4. CORS 配置

**当前问题**：未配置 CORS，可能导致前端跨域请求失败

**优化方案**：
- 配置合适的 CORS 策略
- 允许前端域名的跨域请求

**实现步骤**：
1. 在 `WebMvcConfigurer` 中配置 CORS
2. 设置允许的源、方法和头部

**优先级**：高

---

## ⚡ 性能优化（中优先级）

### 5. Redis 缓存优化

**当前问题**：所有操作直接操作数据库，性能较差

**优化方案**：
- 实现点赞状态的 Redis 缓存（使用 Set）
- 实现关注关系的 Redis 缓存（使用 Set）
- 实现热门帖子排行榜的 Redis 缓存（使用 ZSet）
- 实现用户信息的 Redis 缓存

**实现步骤**：
1. 配置 Redis 连接
2. 创建 Redis 工具类
3. 修改点赞和关注相关方法，使用 Redis 缓存
4. 实现排行榜的 Redis 存储

**优先级**：高

---

### 6. 数据库优化

**当前问题**：数据库查询性能可能不足

**优化方案**：
- 为频繁查询的字段添加索引
- 优化 SQL 查询语句
- 考虑使用数据库连接池

**实现步骤**：
1. 为 `post` 表的 `create_time` 和 `like_count` 字段添加索引
2. 为 `comment` 表的 `post_id` 和 `create_time` 字段添加索引
3. 为 `like_record` 表的 `user_id`、`target_type` 和 `target_id` 组合添加唯一索引
4. 优化复杂查询语句

**优先级**：中

---

### 7. 分页查询优化

**当前问题**：大数据量下分页性能可能较差

**优化方案**：
- 实现 `limit` + `offset` 的高效分页
- 考虑使用游标分页（Cursor Pagination）

**实现步骤**：
1. 优化 `Page` 对象的使用
2. 对于大数据量查询，使用游标分页
3. 添加分页参数的验证

**优先级**：中

---

## 📌 注意事项

1. **兼容性**：优化过程中注意保持接口兼容性
2. **测试**：每完成一个优化项，进行充分测试
3. **备份**：在进行数据库优化前，做好数据备份
4. **渐进式**：采用渐进式优化，避免一次性大改
5. **文档**：及时更新接口文档，反映优化后的变化
